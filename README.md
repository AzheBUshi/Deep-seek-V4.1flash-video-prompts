- **排名片**：全球前十 LLM，12 秒数据动画
- **能力片**：DeepSeek V4.1 Flash 1017，3 分 12 秒像素风数据短片

数据快照：2026-10-20

## ⚠️ 分发边界（重要）

本仓库按**私有仓库**管理。若要改成公开，**必须先删除 `02-像素风能力片/` 整个目录**。

| 目录 | 能否外发 | 说明 |
|---|---|---|
| `01-排名片/` | 可以 | 纯数据动画，无独占内容 |
| `02-像素风能力片/` | **不可** | 含像素风实现手法、帧级节奏、原创结论句 |
| `03-对外分发/` | 可以 | 专为外发准备，已做参数位移 |

`02` 与 `03` 的差别只在「身份参数」：内部画布尺寸、调色板色值、阶梯步数、章节结构、时长、字体、结论措辞。两版都完整可跑，但成品观感不同——不是删减版，是兄弟版。

## 使用方法

### 方式一：交给 AI 编程工具

1. 装 Node 18+ 与 Remotion（`npx create-video@latest`，选 blank 模板）
2. 把提示词整段粘给 Claude Code / Cursor 等工具
3. 自备一份中文像素字体，放到 `public/fonts/`（见下）
4. `npx remotion render <CompositionId> out/video.mp4`

### 方式二：自己按规格实现

读 `03-对外分发/01-对外版简报.md` 拿结构与方向，再读 `02-像素风能力片/02-制作规格.md` 拿实现细节。

## 字体

像素风必须用中文像素字体，Google Fonts 上的 `PressStart2P` / `Silkscreen` **不含中文字形**，用了会静默回落成宋体。

以下均为 OFL 开源许可，可商用：

| 字体 | 说明 |
|---|---|
| 方舟像素字体 Ark Pixel | 字形最规范，12px 设计 |
| Zpix 最像素 | 兼容性好，社区常用 |
| 缝合像素字体 Fusion Pixel | 多语言覆盖最全 |

字体文件不入库（体积与许可版本管理），请自行下载后放入 `public/fonts/`。
