## 0. 三个前置判断

### 0.1 为什么扩到 3 分钟

86 秒里塞 8 个维度，每章只有 10 秒——那不是"讲透"，是"报菜名"。一屏数据刚看清就切走了。

扩到 3 分钟后，每章有 15–30 秒，够&#x505A;**"旧值 → 新值 → 这意味着什么"**&#x7684;三段式。这是数据纪录片和信息图短视频的根本区别。

代价是节奏变慢，所以每一章都加了强制静止段（末尾 20–40 帧不动），让观众的眼睛能落地。

### 0.2 像素风格 ≠ 加个像素滤镜

真像素风有三条硬规则，破了就变成"低清视频"：

1. **只在低分辨率图层里作画，再整数倍放大。** 480×270 内部画布 → 4 倍 nearest-neighbor 到 1920×1080。文字在 480 层里是 8–12px，放大后才锐利。直接在 1920 上画再"加像素化"必然是糊的。
2. **颜色表固定，禁用透明度做渐变。** 淡入如果靠 opacity，会产生调色板外的颜色，像素感立刻崩。正确做法是**像素抖动 + 逐行刷出**。
3. **动效阶梯化，不要丝滑。** 8-bit 机器没有缓动曲线。所有位移量化到 1/12 步进，宁可"顿"不能"滑"。

### 0.3 这支片子必须有一章讲"局限"

只讲能力上限的片子没有可信度。DeepSeek 这次发布本身有争议点（精度取巧、部分评测回退、宕机）。第 10 章专门讲，**这是加分项**——它让前面所有数据都变得可信。

### ch2 · 八项基准拆解（0:30–1:00，最重的一章）

这一章是全片的信息密度峰值，也是**唯一的原创洞察**所在。数据：

| DeepSWE v1.1        | 74.2    | 77.0 | +2.8      |
| ProgramBench        | 20.3    | 29.1 | **+8.8**  |

| Agents' Last Exam   | 31.8    | 35.4 | +3.6      |
| CritPt              | 14%     | 24%  | **+10**   |

**这一章要讲出来的那句话**：

> 知识类只涨了 5.8，执行类涨了 11.1、10、8.8。  
> **它不是变聪明了，是变会干活了。**

这是全片最值得被记住的一句，也是 Part B 收尾的伏笔。

**像素视觉**：九宫格（3×3），每格一个基准。每格内两根竖条：左边灰条是旧值，右边蓝条是新值。  
逐格亮起（每格 40 帧），亮到执行类那三格（Terminal-Bench / CritPt / ProgramBench）时，  
整格边框闪一次橙色，并弹出变化值。  
最后 90 帧画面收拢，只留那句结论，打字机逐字刷出。

### ch6 · 长上下文与多模态（1:54–2:10）

数据：**1M token 上下文 ≈ 1500 页 A4**；支持**文本 + 图像输入**，**只输出文本**。

诚实点：它不是图像生成模型，是"能看图、只会写字"。这一点必须说清，否则容易被误解成多模态生成模型。

**像素视觉**：右侧一个档案柜，抽屉层层拉开，纸张一叠叠堆到 1500（数字滚动）。  
左侧一个"输入口"，一个文字图标和一个图片图标先后飞入，出来只有一个文字图标（表示只输出文本）。

### ch9 · 开源与可部署（2:46–3:02）

数据：**MIT 许可**；**552B 总参 / 16B 激活**（MoE 稀疏，所以快）；可通过 Fireworks / Baseten / DeepInfra / Cloudflare / Together 调用；社区已有 llama.cpp GGUF 量化版可本地跑。

诚实点：**552B 全精度本地跑不现实**（BF16 约 1.1TB），本地能跑的是量化版。不能说"可以在自己电脑上跑满血版"。

**像素视觉**：一个打开的货箱，箱内 8 个插槽，逐个插入卡带（每张卡带标一家托管商）。  
最后一个插槽插的是"本地 GGUF"，插入时箱子整体缩到一个小盒子（暗示量化后体积大幅缩小）。

## 3. 像素风格规范（Remotion 落地参数）

### 3.1 调色板（9 色，不许加）

| 用途             | 色值        |
| -------------- | --------- |
| 背景深            | `#0B0F1A` |
| 面板             | `#131A2B` |
| 网格线            | `#2A3550` |
| **DeepSeek 蓝** | `#4D6BFE` |
| 亮蓝             | `#7C93FF` |
| 白              | `#F2F5FA` |
| 橙              | `#FF5A1F` |
| 青绿             | `#33D6A6` |
| 灰              | `#6B7793` |

**绝对禁止**：任何渐变、任何发光、任何圆角、任何半透明叠加产生的新颜色。

### 3.2 低分辨率画布

```text
外层 Composition：1920 × 1080
内层像素画布：480 × 270
style = { transform: 'scale(4)', transformOrigin: 'top left', imageRendering: 'pixelated' }
```

所有像素内容在 480×270 里画。480 层的 1px = 最终 4px。  
**480 层内字号必须是整数**：8 / 10 / 12 / 16 / 24。不要用 13、18。

### 3.3 中文像素字体（最大的坑）

Google Fonts **没有**简体中文像素字体。`PressStart2P` / `Silkscreen` 只覆盖拉丁字符，中文会**静默掉回系统宋体**，整片立刻露馅。

必须自托管（都是 OFL 许可）：

| 字体                      | 字号   | 特点       |
| ----------------------- | ---- | -------- |
| **方舟像素字体 Ark Pixel**    | 12px | 字形最规范，首选 |
| **Zpix 最像素**            | 12px | 兼容性好     |
| **缝合像素字体 Fusion Pixel** | 12px | 多语言覆盖全   |

```text
字体文件放 public/fonts/，用 @remotion/fonts 的 loadFont() + staticFile() 加载。
480 层内 fontSize 只用 8/10/12/16/24，letterSpacing: 0，fontWeight: 400。
像素字体无真 Bold，伪粗体会把笔画糊死——层级靠颜色和尺寸拉，不靠字重。
若字体缺失，降级 monospace 并在控制台打印警告，绝不静默变宋体。
```

### 3.4 阶梯化动效

```text
const stepped = (p: number, steps: number) => Math.floor(p * steps) / steps;
progress = stepped(spring(...), 12);
显示值 = Math.round(目标值 * stepped(p, 10));
```

### 3.5 淡入淡出怎么代替

| 想要   | 不要用           | 改用                                                   |
| ---- | ------------- | ---------------------------------------------------- |
| 元素出现 | `opacity 0→1` | 逐行刷出 `clipPath: inset(0 0 (100-p*100)% 0)`，p 量化到 8 行 |
| 元素消失 | `opacity 1→0` | 逐行擦除，反向 clipPath                                     |
| 图案层次 | 半透明叠加         | 2×2 棋盘 dither（`repeating-conic-gradient`，仅两色）        |
| 整段转场 | 交叉溶解          | 像素溶解（8×8 方块按 `random(idx)` 依次变白）                     |

**唯一允许 alpha 的地方**：整层 compositing 的整体淡出（用于 Part A→排名片的过渡）。像素图层内部一律不允许。

### 3.6 图标

不要用图标库（全是抗锯齿矢量，跟像素风打架）。两种做法：

- **box-shadow 像素画**：一个 1px `<div>`，用 `boxShadow` 拼像素点阵，适合 9×9 / 16×16
- **SVG + `shapeRendering:'crispEdges'`**：只允许 `<rect>`，坐标必须整数

统一 24×24 像素格（480 层里 = 最终 96×96）。

## 9. 像素风特有失败模式

| 现象 | 根因 | 修法 |
|---|---|---|
| 像"低清视频"不是像素画 | 在 1920 层直接画再缩小 | 480 层作画 + 整数倍放大 |
| 中文变宋体，像素感全崩 | 用了 Google Fonts 像素字体（无中文） | 自托管方舟 / Zpix，loadFont + staticFile |
| 边缘毛刺、斜线发虚 | 缺 `imageRendering:'pixelated'` 或 SVG 缺 `shapeRendering:'crispEdges'` | 两处都补 |
| 淡入时颜色发脏 | 用了 opacity，混出新颜色 | 改 dither + 逐行 clipPath |
| 动效太丝滑像现代 App | 用了默认 spring | 全部过 `stepped(p, 12)` |
| 文字糊成一团 | 非整数字号（13/18）或加了 letterSpacing | 只用 8/10/12/16/24，letterSpacing 0 |
| 伪粗体把笔画糊死 | 给像素字体加 fontWeight 700 | 只允许 400，靠颜色和尺寸拉层级 |
| 图标风格不一致 | 混用 Font Awesome / Lucide | 全部手绘 24×24 像素格 |
| 生成图插进来颜色跳 | AI 图有自己的调色板 | 导入前 posterize 到 9 色 |
| 3 分钟看下来累 | 每章都在动 | 每章末尾强制 20–40 帧静止 |
| ch2 九宫格数字太小看不清 | 9 格挤在 480 层里 | 每格最小 90×70@480，数字不得小于 12px |
