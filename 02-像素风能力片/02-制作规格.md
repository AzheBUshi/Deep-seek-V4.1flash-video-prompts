## 1. 可直接复制的主提示词


### 1.1 完整版（交给 AI 编程工具，一次生成全片）

```text
你是 Remotion 工程师 + 像素美术指导。用 Remotion 4.x + React + TypeScript 制作一支 196 秒、
1920×1080、30fps 的 8-bit 像素风数据纪录片，主题「DeepSeek V4.1 Flash 1017 的能力全景」。

【第一优先：三条像素铁律】
本片的风格成立依赖以下三条，违反任何一条都会退化成"低清视频"而非像素艺术。
这三条的优先级高于任何视觉美化诉求。

1. 低分辨率作画：所有像素内容必须画在 480×270 的内部图层里，再用
   transform: scale(4) + transformOrigin: 'top left' + imageRendering: 'pixelated'
   整数倍放大到 1920×1080。禁止在 1920 层直接绘制像素元素。
   480 层内的 1px 等于最终画面的 4px，这才是正确的像素块尺寸。
2. 固定 9 色调色板，禁止渐变、发光、圆角、半透明叠加。
   允许的颜色只有以下九个，不得引入任何其他色值：
   #0B0F1A（背景） #131A2B（面板） #2A3550（网格） #4D6BFE（主强调）
   #7C93FF（次级高亮） #F2F5FA（主文字） #FF5A1F（警示） #33D6A6（开源标记） #6B7793（次文字）
3. 动效阶梯化：所有位移与数值必须经过量化函数
   const stepped = (p: number, steps: number) => Math.floor(p * steps) / steps;
   位移使用 stepped(progress, 12)，数值滚动使用 stepped(progress, 10)。
   禁止用平滑 spring 直接驱动位移。8-bit 硬件没有缓动曲线，宁"顿"不"滑"。

【技术约束】
1. 从 blank 模板起步。Remotion >= 4.0，React 18，TypeScript strict。
2. 只允许新增一个依赖：@remotion/fonts。
   禁止 d3 / framer-motion / gsap / tailwind / 任何动画库、图表库、图标库。
   所有动效必须用 remotion 的 spring / interpolate / Sequence 手写。
3. 不使用任何外部图片、视频、音频、Lottie。画面全部由 div + SVG rect + 文字构成。
4. 禁止 Math.random()。需要随机时必须用 remotion 的 random(seed)，保证渲染确定性。
5. 禁止 window / document / fetch / Date.now / setTimeout。渲染必须完全可复现。
6. Composition 注册：id="DS1017_PartA"，durationInFrames=5880，fps=30，
   width=1920，height=1080。
7. 文件结构：
   src/Root.tsx
   src/PartA.tsx                 章节编排
   src/pixel/PixelLayer.tsx      480×270 内层容器
   src/pixel/Palette.ts          调色板常量
   src/pixel/stepped.ts          量化函数
   src/pixel/PixelIcon.tsx       像素图标组件
   src/pixel/dither.ts           棋盘抖动
   src/chapters/ch0.tsx ~ ch10.tsx
   src/data.ts
   src/copy.ts                   所有文案字符串集中于此
8. 所有 spring / interpolate 必须显式写参数，并设 extrapolateLeft / extrapolateRight 为 'clamp'。
9. 不留 any、不留 TODO、不留注释掉的废代码。

【字体加载 · 最容易出错的环节】
中文像素字体不在 Google Fonts 上（PressStart2P / Silkscreen 只覆盖拉丁字符，
中文字符会静默回落到系统宋体，风格立刻破坏）。
必须用 @remotion/fonts 的 loadFont()，从 staticFile('fonts/ark-pixel-12px-monospaced-zh_cn.ttf')
加载「方舟像素字体」。
480 层内 fontSize 只允许 8 / 10 / 12 / 16 / 24 这几个整数值，
letterSpacing 一律 0，fontWeight 一律 400。
像素字体没有真正的 Bold 字重，伪粗体会让笔画粘连——层级靠颜色和尺寸区分，不靠字重。
若字体文件缺失，降级为 monospace 并在控制台 console.warn 明确提示，不要静默变成宋体。

【视觉规范】
480 层内边距 16px（等于最终 64px）。网格线 1px #2A3550，间距 8px。
所有图标统一 24×24 像素格，坐标必须为整数。
图标绘制方式二选一：box-shadow 像素点阵（适合 9×9 / 16×16），
或 SVG + shapeRendering:'crispEdges' 且只用 rect。
禁止：圆角、渐变、阴影（投影只能用 2px 硬偏移实色）、emoji、任何调色板外的颜色。

【淡入淡出的正确做法】
元素出现用逐行刷出 clipPath: inset(0 0 (100-p*100)% 0)，p 量化到 8 行。
元素消失用反向逐行擦除。
图案层次用 2×2 棋盘 dither（repeating-conic-gradient，仅两色）。
整段转场用像素溶解（8×8 方块按 random(idx) 依次变白）。
唯一允许 alpha 的位置是整层 compositing 的整体淡出，像素图层内部一律不用 alpha。

【验收标准】
1. npx remotion render DS1017_PartA out/partA.mp4 一次跑通，无报错、无警告。
2. 抽帧检查 0 / 150 / 600 / 1200 / 1700 / 2000 / 2500 / 3000 / 3600 / 4200 / 4800 / 5200 / 5700：
   - 画面中不存在抗锯齿的斜边（放大 4 倍后边缘必须是硬方块）
   - 中文没有回落到宋体
   - 无元素溢出、无重叠
   - 每章末尾存在静止段
   - ch2 九宫格内每格不小于 90×70@480，数字不小于 12px
3. 交付时汇报：创建的文件清单、渲染耗时、是否发生字体降级、
   以及全部文案有无被缩短或改写。
```

## 5. 像素风验收标准

### 5.1 必查五项

| 检查项  | 不合格表现        | 判定方法               |
| ---- | ------------ | ------------------ |
| 像素纯度 | 斜边有抗锯齿毛刺     | 抽帧放大 400%，边缘必须是硬方块 |
| 中文渲染 | 中文笔画变成曲线     | 同上，笔画必须是方块不是圆弧     |
| 调色板  | 出现半透明混色、渐变   | 取色统计，只允许九个色值       |
| 动效质感 | 位移过滑、像现代 App | 逐帧步进检查，应有明显台阶      |
| 章节留白 | 全程无静止，看得累    | 每章末尾应能数出 20–40 帧不动 |

### 5.2 常见故障与修法

| 现象           | 根因                                      | 修法                               |
| ------------ | --------------------------------------- | -------------------------------- |
| 像"低清视频"而非像素画 | 在 1920 层直接画再缩小                          | 480 层作画 + 整数倍放大                  |
| 中文变宋体        | 用了不含中文字形的像素字体                           | 自托管方舟 / Zpix + loadFont          |
| 边缘毛刺、斜线发虚    | 缺 imageRendering 或 SVG 缺 shapeRendering | 两处都补 'pixelated' / 'crispEdges'  |
| 淡入时颜色发脏      | 用 opacity 混出新颜色                         | 改 dither + 逐行 clipPath           |
| 文字粘连糊成一团     | 非整数字号或加了 letterSpacing                  | 只用 8/10/12/16/24，letterSpacing 0 |
| 伪粗体把笔画糊死     | 给像素字体设了 fontWeight 700                  | 只允许 400，靠颜色尺寸拉层级                 |
| 图标风格不统一      | 混用了矢量图标库                                | 全部手绘 24×24 像素格                   |
| ch2 九宫格数字看太清 | 9 格挤在 480 层                             | 每格 ≥90×70@480，数字 ≥12px           |

## 6. 与外部片段的拼接规范

本片 3:16 处预留一个插入位，用于接入外部已有素材（如排行榜片段）。该片段不由本工程生成。

### 6.1 进出点

| 接缝         | 从哪出             | 从哪进                      | 处理                        |
| ---------- | --------------- | ------------------------ | ------------------------- |
| 主片 → 外部片段  | 第 5880 帧（196s）末 | 外部片段第 0 帧                | 主片末 12 帧压到全黑，硬切           |
| 外部片段 → 收尾段 | 外部片段最末帧         | **PartB 第 60 帧**（非第 0 帧） | PartB 前 60 帧为黑场 + 光标，天然缓冲 |

### 6.2 必须统一的三个锚点

否则两支片接起来会像两部作品：

1. **底色**：本片背景为 `#0B0F1A`。外部片段若用其他深色（如 `#0B0E14`），差异足以被肉眼察觉，需先统一。
2. **字体**：本片使用像素字体，外部片段若使用矢量字体（如 Inter），**接缝处必须有一帧全黑隔开**，否则字体会当着观众的面变样。
3. **强调色**：若外部片段有独立强调色，需与本片的 `#4D6BFE` 协调，避免两个高饱和色同时出现。

### 6.3 转场限制

**禁止交叉溶解。** 像素风格的转场词汇只有两种：「全黑 + 光标」与「CRT 关机收束」。加叠化会立即破坏风格统一。
